# VDocQ Frontend

Frontend app for VDocQ built with React + Vite.

## Run Frontend

Location: `queueless-frontend`

```powershell
cd D:\backup\OneDrive\Desktop\queueless\queueless-frontend
npm install
npm run dev
```

## Build Frontend

```powershell
cd D:\backup\OneDrive\Desktop\queueless\queueless-frontend
npm run build
npm run preview
```

## Run Backend (for API)

Location: `backend/QueueLess/backend`

```powershell
cd D:\backup\OneDrive\Desktop\queueless\backend\QueueLess\backend
uvicorn app.main:app --reload
```
